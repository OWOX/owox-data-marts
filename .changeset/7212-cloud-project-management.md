**Manage Cloud projects in OWOX Data Marts**

Cloud users previously opened Platform to create a project from the project menu or to change a project's name. Now you can create a project from the OWOX Data Marts menu and open it as soon as it is ready.

Project Admins can rename or delete a project in **Project Settings → Overview**. If outstanding billing delays deletion, the project shows **Removing**. After deletion, OWOX opens your updated list in **My profile → Projects**. When you delete your last project, OWOX opens **My profile → Overview**.

See [Manage Cloud projects](../../docs/project/#manage-cloud-projects).
