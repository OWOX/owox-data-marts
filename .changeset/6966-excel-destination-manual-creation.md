# Microsoft Excel destinations can now be created from the web app

**Microsoft Excel** is back in the destination type list. While the OWOX add-in
for Excel was under Microsoft Marketplace verification, the only way to get an
Excel destination was to let the add-in create one on your first report run.
Now you can also add one yourself from the Destinations page: give it a title
and save, there are no credentials to fill in.

The automatic path is unchanged: if your project has no Excel destination you
can use, the add-in still creates one the first time you build a report.
