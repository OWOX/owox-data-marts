**Permission warnings are easier to act on: they say which role or access you need**

A Business User who opened the Connector Builder saw "The connector builder needs editor access". The project roles are Project Admin, Data Owner and Business User, so it was not clear which role to ask for. Now the message names the Data Owner and Project Admin roles and links to **Project settings → Members**, where a Project Admin changes roles.

On the Data Quality tab, the disabled **Run** button now says that you need edit access to this Data Mart. Before, it said "Editor access is required".

See [Roles and Permissions](../../docs/project/roles-and-permissions.md) for what each role can do.
