**Support MCP protocol 2026-07-28 and alert on compatibility failures**

The MCP endpoint now understands the `2026-07-28` protocol revision, including the `server/discover`
method — Claude clients that probe for it before connecting no longer get rejected. Existing clients
on 2024–2025 protocol revisions keep working unchanged. Rejections of a protocol revision the server
is expected to support are now logged at error level so production alerting catches them, instead of
accumulating silently as warnings. See [MCP Server](../../docs/getting-started/setup-guide/mcp.md) for
connection and troubleshooting guidance.
