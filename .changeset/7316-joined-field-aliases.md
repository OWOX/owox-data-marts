**Keep inherited Output Aliases in sync with Data Mart titles when editing joined fields**

If you changed any setting for a joined field and later renamed its Data Mart, reports could still show the old title. The inherited **Output Alias** now follows title changes whether you edit joined fields in the OWOX Data Marts web interface or through MCP.

If a join still shows an old title, clear its **Output Alias** to use the current title. See [Report Fields](../../docs/getting-started/setup-guide/joinable-data-marts.md#step-4-configure-report-fields).
