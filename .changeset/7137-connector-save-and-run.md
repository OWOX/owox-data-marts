**Save & Run a connector Data Mart from the setup sheet**

Before this release, Save in the Set Up Connector sheet only saved the settings. A new Data Mart stayed a draft, and no data loaded until you found Publish & Run Data Mart. Now the last button of the sheet is "Save & Run".

- For a draft Data Mart, "Save & Run" saves the settings, publishes the Data Mart and starts the first run.
- For a published Data Mart, "Save & Run" saves the settings and starts a run.
- To save without a run, open the menu next to the button and click "Save".
- If the Storage of the Data Mart is not set up, the sheet shows only "Save".
