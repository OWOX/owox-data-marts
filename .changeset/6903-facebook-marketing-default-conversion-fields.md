# Select conversions and conversion values by default in Facebook Marketing insights

The `conversions` and `conversion_values` fields are now selected by default for every Facebook Marketing insights endpoint, including all breakdown variants (by age and gender, country, device platform, link URL asset, product ID, publisher platform and position, region, ad set, and campaign). New Data Marts built on these endpoints include conversion data without manual field selection.
