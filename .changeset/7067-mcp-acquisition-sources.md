**Track MCP signup sources**

OWOX Cloud can attribute users and newly created projects to Claude or ChatGPT during MCP sign-in. The first known integration fills an empty user source. A recorded source is preserved on later sign-ins.

An existing account's empty source is filled when the account signs in through this MCP flow. Connecting a client through an existing session does not backfill it.

Unknown clients continue to use the OWOX Data Marts source.
