**Track MCP signup sources**

OWOX Cloud can attribute new users and projects to Claude or ChatGPT when registration starts from an MCP connection. Existing creation sources are preserved when users connect another client.

Unknown clients continue to use the OWOX Data Marts source. See [MCP acquisition sources](../../docs/contributing/mcp-acquisition-sources.md) for the cross-service rollout and reporting configuration.
