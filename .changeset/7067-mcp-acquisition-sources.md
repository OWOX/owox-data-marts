**Track MCP signup sources**

OWOX Cloud can attribute users and newly created projects to Claude or ChatGPT during MCP sign-in. The first known integration fills an empty user source, including for an existing account. A recorded source is preserved on later sign-ins.

Unknown clients continue to use the OWOX Data Marts source. See [MCP acquisition sources](../../docs/contributing/mcp-acquisition-sources.md) for the cross-service rollout and reporting configuration.
