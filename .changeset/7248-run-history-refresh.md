**See new runs in Run History without a page reload**

Run History, the log of every run, showed a run that started outside the page late. A run from a schedule, an AI assistant or another browser tab came up after up to 30 seconds on a Data Mart, and on the project Run History only after a page reload. To see it at once, people reloaded the whole page.

Now the Run History of a Data Mart and of the project has a **Refresh** button. It loads the newest runs and keeps the runs that are already loaded. The Run History of a Data Mart also updates as soon as you come back to its browser tab. See [Create your first Data Mart](../../docs/getting-started/first-data-mart.md).
