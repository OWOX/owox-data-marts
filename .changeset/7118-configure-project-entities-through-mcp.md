**Configure Data Marts, Contexts, and project descriptions from your AI assistant**

You can now use [MCP](../../docs/getting-started/setup-guide/mcp.md) to create and configure Data Marts on existing storages, manage their schemas and relationships, and publish them. Your assistant can list project members to find the right people for owner and Context assignments. Project admins can also create and manage Contexts, assign their members, and update the project description.

Your assistant can also discover connectors, their setup parameters, nodes and fields, preview dynamic choices, and reuse configurations from Data Marts you can edit. Credentials are reused on the server using the selected Data Mart and configuration IDs. For new authorization, the assistant can link you to that draft's setup in OWOX, then continue after you save it. Tool responses include the next setup steps.

The tools respect your existing project permissions. Connector secrets stay masked in configuration responses, and new storage connections and credentials are configured in the OWOX UI.

You can start an assisted setup from the Create Data Mart page or continue after creating a draft in OWOX. ChatGPT and Claude buttons let you choose a browser or desktop app and pass an English prompt with your project and Data Mart context, with a copy option for an existing chat.
