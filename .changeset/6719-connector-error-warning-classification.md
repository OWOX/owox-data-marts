# Cleaner connector run logs: warnings for issues you can fix yourself

Connector run logs now show two changes.

Failures split into warnings and errors, so you can tell at a glance what
needs you to act. Warnings mark issues you can fix yourself — like expired
credentials or a canceled run. Errors mark issues our support team can help
you resolve.

Logs are also easier to scan. Each crash appears as a single entry instead of
several, and duplicate entries are gone.
