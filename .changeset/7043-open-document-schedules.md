**Open the Google Sheet a scheduled report fills, right from Triggers**

Checking the results of a report-run schedule used to mean opening the row's info card and
finding **Open in Google Sheets** tucked inside it — an action many people never discovered.
On the **Triggers** page under **Data Marts**, and in each Data Mart's **Triggers** tab, the
scheduled report's name is now a link, marked with an external-link arrow, that opens that Google
Sheet in a new tab.

![The Data Marts Triggers page with a Report Run row whose report name, New report, is a link with an external-link arrow](https://imagedelivery.net/zKr-4bdC5CBGL2DuuEmvYw/5610fa3a-0064-4a33-6b5e-e0aa62a73600/w=800)

- Shows only for report-run triggers whose destination is Google Sheets; connector runs, Data
  Quality checks, and other destination types are unaffected.
- See [Report Trigger](../../docs/getting-started/setup-guide/report-triggers.md) for how
  report-run schedules work.
